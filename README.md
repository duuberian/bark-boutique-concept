# Bark Boutique — independent website concept

Personalised presentation prototype by Daniel. Not commissioned, endorsed or operated by Bark Boutique. No live booking, backend, persistence or customer-data collection. Enquiry preview runs in the browser only; use fictional details.

## Hosting
Static HTML/CSS/JS, served on GitHub Pages from the main branch root. No build dependencies or paid services. Google Fonts is an external font dependency, with local font fallbacks. Run locally with `python -m http.server 8765`.

## Before any live business use
Owner approval of copy/images, confirmed prices/service area, agreed enquiry delivery channel and privacy notice, appropriate spam protection, and end-to-end delivery testing. Existing Wix Forms may suit the live enquiry workflow without a custom backend.
